# OBS Mobile

Android screen recorder (screen + mic, MP4). 

## APK kaise banaye (GitHub se)
1. Is poore folder ko apne GitHub repo me upload karo.
2. Repo > Actions tab > "Build APK" > Run workflow (ya push par auto chalega).
3. 3-5 min baad run khulega, neeche Artifacts me `OBS-Mobile-APK` download karo.
4. Zip kholo, `app-debug.apk` phone me install karo.
